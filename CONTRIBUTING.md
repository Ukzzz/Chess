# Contributing to Grandmaster Chess

Thank you for your interest in contributing to Grandmaster Chess! We welcome contributions to improve the UI, add new features, or fix bugs.

## How to Contribute

1. **Fork the Repository**: Create a fork of the project and clone it locally.
2. **Create a Branch**: Use a descriptive branch name (e.g., `feature/analytics-dashboard` or `fix/move-validation`).
3. **Make Changes**: Ensure your code follows the existing style and is well-documented.
4. **Test Your Changes**: Verify that the game still runs correctly and multiplayer functionality is intact.
5. **Submit a Pull Request**: Provide a clear description of your changes and why they are needed.

## Style Guidelines

- **JavaScript**: Use modern ES6+ features and maintain consistent naming (camelCase).
- **CSS**: Use Tailwind CSS utility classes where possible. For custom styles, add them to `index.ejs`.
- **HTML/EJS**: Use semantic HTML and maintain accessibility.

## Feedback & Issues

If you find a bug or have a feature request, please open an issue in the repository.
